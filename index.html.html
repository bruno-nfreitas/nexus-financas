Binance Connect 🔶

Conecte sua conta Binance e opere com saldo real

🔶
Conectar Binance
Conecte sua conta Binance usando suas chaves de API. Seus fundos ficam na Binance — o app apenas visualiza e envia ordens em seu nome.
⚠️
Use apenas chaves com permissão de leitura + trading. NUNCA habilite saques na chave API. Crie uma chave específica para este app.
📋 Como criar sua API Key na Binance
1. Acesse binance.com → Perfil → Gerenciar API
2. Clique em Criar API → Escolha "API gerada pelo sistema"
3. Habilite apenas: Leitura e Spot & Margin Trading
4. NÃO habilite saques! Isso é uma medida de segurança.
5. Recomendado: restrinja o IP ao seu endereço atual
6. Copie a API Key e Secret Key e cole acima
